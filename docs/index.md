# Radio Platform

Radio Platform lets an organisation manage its **Uniden SDS200 radio
scanners** from a web browser, wherever the scanners are installed.
People can see what each scanner is hearing, adjust it, listen live and
look back at past transmissions without standing in front of the radio.

It is open source (Apache 2.0) and talks to the scanners over their own
network connection. No ProScan, Sentinel, USB cable or other proprietary
software is needed.

!!! warning "Not yet tested on real scanners"
    Everything so far has been built and tested against a **simulated**
    SDS200. No feature has been verified on SDS200 hardware yet. See
    [Project status](overview/project-status.md).
