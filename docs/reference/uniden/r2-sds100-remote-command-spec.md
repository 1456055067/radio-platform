## Why it no longer matters much

R6, the *SDS100 / SDS200 Remote Command Specification* v1.02, lists
"0.01, 2018-04-13, created new based on BCD536HP/BCD436HP Remote Command
Specification Version 1.05" as its first edition. The version and date
match R2, so R2 is an earlier edition of R6.

The questions the project hoped R2 would answer are now tracked against R6:

| Item | Where it stands |
|---|---|
| `KEY` key-code table | In R6 for the BCD536HP and SDS100; no SDS200 column. See [R6](r6-sds-remote-command-spec-v1-02.md) |
| SDS changes from R1 | Listed on the [R6](r6-sds-remote-command-spec-v1-02.md) page |
| `GLG` | Not in R6; still community only |

Obtaining R2 itself is no longer an action item.
